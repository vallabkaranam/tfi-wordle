# MD-08 — Full Codebase Cleanup & Canonical Refactor Pass

## Objective
Perform a thorough cleanup and refactor across the entire codebase (frontend and
backend) now that deployment is stable, to ensure the project is clean, modular,
canonical, and production-ready.

This milestone intentionally preserves existing application behavior and API
compatibility. No feature changes.

---

## Scope

### Repo-wide
- Remove unused code, files, and dependencies
- Normalize naming conventions and folder structure
- Improve consistency (formatting, linting, typing)
- Add or improve comments/docstrings where clarity is needed
- Ensure imports and module boundaries are clean and intentional

---

### Frontend (Next.js)
- Consolidate API client logic and shared types
- Tighten component responsibilities (single-responsibility components)
- Remove dead or unused components/helpers
- Normalize imports and directory layout
- Ensure environment variable usage is canonical:
  - `NEXT_PUBLIC_API_URL` only

---

### Backend (FastAPI)
- Cleanly organize routes, services, and models
- Normalize response schemas using Pydantic
- Ensure consistent error handling
- Preserve non-blocking startup and mock fallback behavior
- Remove unused or legacy code paths where safe

---

## Guardrails (Hard Rules)
- Do NOT change gameplay rules or UI flows intentionally
- Do NOT change deployment behavior
- Do NOT introduce a database or new data sources
- Do NOT break existing API endpoints or response shapes

---

## Verification
- Frontend: `npm install && npm run build`
- Backend boots cleanly and endpoints still respond:
  - GET `/api/movies`
  - POST `/api/guess`
  - GET `/api/daily`

---

## Deliverables
- A single PR or commit series implementing the refactor
- A concise summary of changes explaining what was cleaned up and why it’s safe
