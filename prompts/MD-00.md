# MD-00 — Git Hygiene Fix

## Purpose
Ensure all core source code is properly tracked by git before any further work.

## In Scope
- Add untracked frontend source directories to git:
  - frontend/src/components
  - frontend/src/lib
- Ensure no accidental files (node_modules, caches) are added
- Verify git status is clean after staging

## Out of Scope
- No code changes
- No refactors
- No formatting changes

## Success Criteria
- All core source code is tracked
- git status shows only intentional changes
