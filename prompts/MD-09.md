# MD-09 — Real Data Layer Canonicalization (TMDB-first + Deterministic Fallback)

## Objective
Replace “mock-only” behavior with a canonical, deterministic real-data pipeline.

Primary source: TMDB (when `TMDB_API_KEY` is present)  
Fallback: a versioned, curated dataset committed to the repo (no hallucinations).

This milestone improves data realism without changing core game rules yet.

---

## Requirements

### 1) Canonical Data Contract
Define a single internal `Movie` model used across the app (backend is source of truth).
At minimum:
- id (string or int)
- title (string)
- year (optional)
- language (optional)
- poster_url (optional)
- tags/categories needed by the game (if already used)

Backend must return this shape consistently.

---

### 2) TMDB Integration (Primary)
When `TMDB_API_KEY` is set:
- Fetch and cache a list of Telugu movies from TMDB
- Normalize TMDB results into the canonical `Movie` schema
- Use in-memory cache (Render free-tier safe)
- Keep startup non-blocking (do not introduce blocking I/O in startup path)

Notes:
- Filter should target Telugu language (e.g., language/region filters) as best as possible.
- Prefer deterministic ordering rules (e.g., by popularity or release date) so daily selection is stable.

---

### 3) Deterministic Fallback Dataset (No Key Required)
When `TMDB_API_KEY` is missing or TMDB fetch fails:
- Serve from a curated dataset committed in-repo, e.g.:
  - `backend/src/data/telugu_movies.json`
- Dataset must be stable, version-controlled, and free of runtime network dependency.

No scraping at runtime.

---

### 4) No Hallucination Policy
- Do not use LLMs to invent movie facts/metadata.
- Do not use “agent browsing” as a runtime dependency.
- Any data must come from:
  - TMDB API responses, OR
  - a committed local dataset file.

---

## Verification
- With TMDB key:
  - `/api/movies` returns TMDB-derived list (normalized)
- Without TMDB key:
  - `/api/movies` returns local dataset list
- `/api/daily` still works in both cases
- Frontend builds and deploy remains green

---

## Deliverables
- TMDB data fetch + normalization logic
- Local dataset file committed
- Clear docs update (env var behavior + data sources)
