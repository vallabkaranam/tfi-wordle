# MD-11 — Canonical Metadata Layer + Final Structural Cleanup

## Objective
Introduce a deterministic Tollywood metadata layer for gameplay fields
(hero, heroine, director, music, producer) and perform final structural cleanup.

This is the final structural milestone before gameplay logic work.

---

## Architecture

### 1) TMDB Layer (already working)
Provides:
- id (tmdb_id)
- title
- year
- language
- poster_path

### 2) Local Metadata Layer (NEW)
File:
backend/src/data/tollywood_metadata.json

Schema:
{
  "tmdb_id": number,
  "hero": string,
  "heroine": string,
  "director": string,
  "music": string,
  "producer": string
}

---

## Join Logic

- Load TMDB movies at startup.
- Load metadata file.
- Build a map keyed by tmdb_id.
- Only include movies that:
    - exist in TMDB results
    - have metadata entry
- Exclude all others from playable pool.

No partial entries.
No "Unknown" placeholders.
No fallback guessing.

---

## Cleanup Requirements

1) Remove any placeholder logic that sets:
   - hero = "Unknown"
   - director = "Unknown"
   - etc.

2) Remove any unused schema fields.
3) Remove unused helper files.
4) Remove dead code paths related to old fallback metadata.
5) Ensure Movie schema is clean and correct.

---

## Final Movie Schema (Canonical)

{
  "id": number,
  "title": string,
  "year": number | null,
  "language": string,
  "poster_path": string | null,
  "hero": string,
  "heroine": string,
  "director": string,
  "music": string,
  "producer": string
}

All gameplay fields must be present.
