# MD-05 — Frontend Build Fix (Render Path Aliases)

## Objective
Fix the Render build failure caused by unresolved `@/…` imports in the frontend.

## Evidence (Render Logs)
- Module not found: Can’t resolve `@/lib/api`
- Module not found: Can’t resolve `@/lib/utils`
- Build exited with status 1

## Desired End State
- Frontend `next build` succeeds on Render
- No unresolved `@/…` imports remain
- Changes are minimal and safe for the existing codebase
- No behavior changes

## Scope
Fix path resolution in the frontend by replacing `@/…` imports with robust imports that work in the Render build.

### Allowed
- Replace `@/…` imports with correct relative imports (e.g., `../lib/api`)
- Or configure `tsconfig/jsconfig` paths if present and reliable

### Not Allowed
- No new features
- No UI redesign
- No runtime behavior changes
- No dependency upgrades

## Completion Criteria
MD-05 is complete when:
- All `@/…` imports are resolved (preferably none remain)
- `next build` succeeds locally and on Render
- Render frontend deploy succeeds
