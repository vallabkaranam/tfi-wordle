# MD-12 — Core Gameplay Engine

## Objective
Implement canonical Wordle-style gameplay logic:

- 5 attempts
- Per-field feedback
- Chronological attempt tracking
- Win/Lose state
- Answer reveal at game end

No UI animations.
No styling.
Backend + minimal frontend adjustments only.

---

## Backend Changes

### 1) Update /api/guess

Input:
{
  "movie_id": number,
  "previous_attempts": [ ... ]  // client sends attempt history
}

Behavior:
- Compare guessed movie metadata with daily answer
- Generate per-field feedback:
    - hero
    - heroine
    - director
    - music
    - producer
    - year
- Append to attempts
- Determine:
    - status = "in_progress" | "won" | "lost"
- If won or lost:
    - Include full correct answer in response

Max attempts = 5

---

### 2) Update /api/daily
Ensure daily movie selection is deterministic (based on date hash or index).

---

## Response Shape

{
  "attempts": [...],
  "remaining_attempts": number,
  "status": "in_progress" | "won" | "lost",
  "answer": { ... } | null
}

---

## Frontend Adjustments

- Maintain attempts in state.
- Render guesses in chronological order.
- Disable guessing when:
    - status != "in_progress"
    - remaining_attempts == 0
- Show answer section when game ends.

---

## Verification

- 5 guesses max
- Win triggers early stop
- Lose after 5
- Correct answer revealed at end
- Frontend builds
- API remains clean
